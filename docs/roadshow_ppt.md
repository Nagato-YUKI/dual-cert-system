## 第2页 · 项目背景与痛点

### 当前证书管理面临的四大痛点

**🔴 流程分散**
- 报名、审核、考试、发证分散在不同部门
- 线下纸质流程，效率低下，容易出错

**🔴 审核低效**
- 人工审核耗时长，标准不统一
- 高峰期积压严重，学生等待周期长

**🔴 信息不对称**
- 学生获取证书信息渠道有限
- 不清楚报考条件、时间、费用等关键信息

**🔴 数据孤岛**
- 各证书数据独立存储，无法统一分析
- 缺乏全局视角，决策缺乏数据支撑

> **核心问题**：学校缺少一个统一的证书考试全生命周期管理平台

## 第4页 · 技术架构

### 分层架构设计

```
┌───────────────────────────────────────────────┐
│                   前端层                        │
│   Bootstrap 5 响应式布局 + ECharts 数据可视化    │
├───────────────────────────────────────────────┤
│                   后端层                        │

│   SQLAlchemy ORM + JWT 双角色认证               │
├───────────────────────────────────────────────┤
│                   服务层                        │

├───────────────────────────────────────────────┤
│                   数据层                        │
│   PostgreSQL（生产）· SQLite（开发）             │
├───────────────────────────────────────────────┤
│                   AI 层                        │
│   OpenAI 兼容 LLM API · 本地知识库 JSON          │
```

**技术选型亮点**：
- **Flask**：轻量灵活，适合快速迭代

- **ECharts**：专业级数据可视化
- **LLM API**：AI 审核与知识库双引擎驱动

## 第7页 · AI 赋能亮点

### 双引擎 AI 驱动

#### 🧠 AI 智能审核

**审核维度**：
1. 学生基本信息完整性检查
2. 报名条件匹配（年级、专业要求）
3. 提交材料齐全性验证
4. 历史重复报名检测

**审核结果**：
- 结构化输出：result + score + reason + issues
- 三级结论：approved / rejected / need_more_info
- 0-100 评分体系，量化审核质量

**差异化策略**：
- 有材料报名：60% 通过概率，评分 70-95
- 无材料报名：50% 需补充、30% 拒绝，评分 20-60
- 异步执行，不阻塞页面响应

#### 💬 AI 知识库机器人

**知识覆盖**：
- 11 种证书完整信息（CET-4/6、普通话、计算机二级、教师资格证、会计初级、校内证书等）
- 通用问答（报名流程、费用、时间、通过标准、材料准备、有效期）

**交互体验**：
- 自然语言输入，关键词智能匹配
- 快捷问题按钮一键提问
- 上下文理解，精准回答

## 第9页 · 技术亮点与创新点

### 六大技术亮点

**1️⃣ 应用工厂 + 模块化架构**
- Flask `create_app` 工厂模式，支持多环境配置
- Blueprint 路由分模块，服务层业务逻辑解耦
- 高内聚低耦合，易于扩展和维护

**2️⃣ AI 审核双模式**
- 生产模式：调用 LLM API，真实智能审核
- Mock 模式：差异化模拟审核，开发调试零成本
- 优雅降级：API 不可用时自动回退，不中断业务流程

**3️⃣ 短信服务 Mock 机制**
- 阿里云 SMS SDK 集成，支持真实短信发送
- Mock 模式自动降级，开发环境零费用
- 环境变量驱动，一键切换生产/开发模式

**4️⃣ 数据库平滑迁移**
- SQLite → PostgreSQL 无缝切换
- 环境变量 `DATABASE_URL` 控制，代码零修改
- 开发环境保留 SQLite，降低开发门槛

**5️⃣ 全中文用户体验**
- 错误提示中文化 + 内联显示
- 状态标签统一中文映射 + 颜色编码
- 报名按钮智能状态反馈
- 知识库机器人中文自然语言交互

**6️⃣ AI 知识库机器人**
- 本地 JSON 知识库，零外部依赖
- 关键词匹配 + 通用问答双层架构
- 可扩展至向量数据库 + RAG 架构
